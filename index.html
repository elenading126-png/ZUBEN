开启后手机/电脑自动同步进度，仅需配置一次，数据存在你自己的 GitHub 私有 Gist。不想用直接关闭，进度仍存本机。

如何获取 Token？（免费，约 30 秒）
1. 打开 github.com → 右上角头像 → Settings
2. 左侧最下方 Developer settings → Personal access tokens → Tokens (classic)
3. Generate new token (classic) → Note 填 zuben → 勾选 gist 权限 → 过期时间建议设 1 年或无
4. 拉到底 Generate token → 复制那串 ghp_... 粘到上面

提示：Token 仅保存在你本机浏览器，不会上传给任何第三方。建议只用「只勾了 gist 权限」的令牌。
